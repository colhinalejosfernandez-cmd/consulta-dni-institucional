# Consulta de DNI

Aplicación web de uso institucional que permite consultar información de identidad mediante el número de Documento Nacional de Identidad (DNI), utilizando los servicios autorizados de RENIEC a través de PIDE.

El sistema está diseñado para presentar los datos personales y la fotografía disponibles, facilitando la verificación de identidad por parte del personal autorizado.

**Estado:** En desarrollo.

**Uso:** Exclusivo para personal autorizado.
