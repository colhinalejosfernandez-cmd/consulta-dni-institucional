# Consulta de DNI

## Descripción

Sistema web desarrollado para facilitar la consulta de información de identidad mediante el número de Documento Nacional de Identidad (DNI).

La aplicación permite acceder a información proporcionada por los servicios autorizados de RENIEC, presentando los datos personales y la fotografía correspondiente, según la información disponible.

## Finalidad

Facilitar la consulta y verificación de información de identidad, contribuyendo a una atención más organizada y eficiente dentro de la institución.

## Acceso y uso

El sistema está destinado exclusivamente al personal autorizado de la institución.

La información consultada es de carácter confidencial y debe utilizarse únicamente para los fines institucionales permitidos.
